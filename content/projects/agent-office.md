AgentHub is a desktop command center for managing a team of AI agents — Claude, Codex, Cursor, Gemini, and Qwen — from a single interface built with pixel-art aesthetics.

### Core Features
- **Pixel-Art Office View:** An interactive isometric canvas with multiple rooms (Office, Server Room, Break Room, Data Lab) where AI agents are visualized as animated pixel sprites working at desks.
- **Multi-Agent Orchestration:** Assign tasks to specialized agents with auto-dispatch rules — research goes to Gemini, code generation to Codex, scraping to Qwen, and refactoring to Cursor.
- **Daemon Controls:** Toggle agents on/off as persistent background daemons with task queues, scheduling, and live log output.
- **Built-in CRM:** SQLite-powered database for managing contacts, leads, scrape results, saved scripts, and inter-agent messaging.
- **Terminal Panels:** Embedded terminal views per agent showing real-time command output and status.
- **Chat Feed:** Simulated inter-agent conversation bubbles adding personality to the workspace.
- **Task Queue System:** JSON-based task management with auto-dispatching based on task type and a configurable chain of command.

The app turns AI-powered development workflows into a visual, manageable experience — making multi-agent orchestration feel like running a small office.

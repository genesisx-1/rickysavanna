I built a CRM platform with automated outreach and pipeline management.

The frontend is built with Next.js/TypeScript, and the backend uses Node/Express or Next API routes. I created full documentation for setup, deployment to Railway, and maintaining the task queue system.

The app features authentication, dashboard views, lead management, and automated workflows that handle outreach, follow-ups and pipeline tasks.
